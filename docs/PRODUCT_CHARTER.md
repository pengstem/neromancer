## 1. 为什么做 Neromancer？（痛点与破局）

市面上的记录工具往往陷入两难：
- **为什么不用传统备忘录？**  
  灵感迸发往往只有几秒钟。备忘录需要你停下来打字、想标题、决定放在哪个文件夹、顺手排版——还没排完版，最初最鲜活的那个念头已经散了；日积月累后，手机屏幕上满屏都是没有组织的碎文字，下滑半天还看不到下一条，打开就想关掉。
- **为什么不直接一上来丢给通用聊天 AI（ChatGPT）？**  
  大模型的知识过于广泛，一上来就把半成品交给它，它会立刻给出一个**正确但平庸的百科答案**，把用户独特甚至“一开始带点有趣错误”的路线磨平。

因此，Neromancer 的核心定位是 **“Notion + ChatGPT for Random Sparks”**，只死磕两件事：
1. **第一：少阻力** —— 看到就想开口说、桌面悬浮球随手丢进去、不设任何排版和分类前置门槛。
2. **第二：低于平庸** —— 保留原汁原味的初始火花，用像朋友聊天一样好读的口语做整理，用追问把灵感养大，只在需要落地时给出从零到一的可执行方案。

## 2. 六大核心能力与原型对应

| 核心能力 | 解决的问题 | 本原型落地方案 |
| :--- | :--- | :--- |
| **① 桌面悬浮球 / 快捷入口** | 手机或电脑正忙时切换应用记录太慢 | 安卓支持 `neromancer://capture` 快捷入口与顶栏速记胶囊；桌面端支持无边框置顶悬浮球与 `Cmd/Ctrl+Shift+I` 热键 |
| **② 极速多模态捕捉** | 手机端打字排版阻力大 | 右下角「🪶 记灵感」拉起底部抽屉：安卓原生 `AudioRecord` 语音、相机拍照/相册选图、短句与场景线索一次落盘 |
| **③ 记忆球可视化预览** | 纯文字回顾心智负担重、一眼看不出重点 | 安卓 Material 3 风格《头脑特工队》多彩 GPU 记忆球 + 场景轻卡片 + Tag 微火花提醒 |
| **④ 实时回访联想** | 记过就忘、不知道以前也想过类似的事 | 输入或搜索时实时匹配旧记忆球与原始证据，主动弹出“之前某天记过相关想法” |
| **⑤ AI 自主组织 + 原始证据** | 碎片越积越乱，但合并后怕丢掉当时原话 | 滑入「思维空间」自动去重归并成目录/星图，详情页「🗂️ 原始证据」永久保留不可篡改的原录音与原图 |
| **⑥ 酷分享与只读漫游碰撞** | 自己的废想法腻了，想从别人奇思妙想找刺激 | 导出高颜值 PNG 海报并唤起安卓系统分享面板（`mygo.Share`）与 `.orb.json` 胶囊；在无评论区的只读漫游中触发「⚡ 跨界碰撞」 |

## 3. 核心演示剧本（供录制演示视频参考）

### 第一幕：极速捕捉与“蓝色花瓶郁金香”自动归并（90 秒）
1. 在安卓手机（或 `go tool mygo dev` `412×892` 手机预览窗口）打开主界面进入 **「✨ 星海」**，展示不同颜色、不同权重大小的发光记忆球，以及横向 Tag 筛选胶囊。
2. 点右下角 **「🪶 记灵感」** 拉起底部抽屉（或点击顶栏 **「🫧」** 速记球），演示用手机麦克风直接说话转写或拍照输入，展示输入瞬间触发的 **「✨ 联想提醒」**。
3. 展示经典案例 **《用一个蓝色花瓶养一株郁金香》**：向观众解释它原本是隔了 23 分钟随口记下的两条毫不相干的碎片——*“买一盆郁金香放在阳台上养”* 和 *“郁金香的花瓶应该是蓝色的”*，DeepSeek 自动识别出同源主题，将其去重归并成同一颗珊瑚粉记忆球。

### 第二幕：进入思维空间与“原始证据”保真（60 秒）
1. 切换底部栏或向下滑入 **「🧭 思维空间」**，指出右下角按钮已经从 **「🪶 记灵感」** 变形为 **「🧭 组织」**。
2. 点击 **「🧭 组织」** 在 **目录树 → 关联星图 → 场景卡片** 之间切换，展示无需翻长文字就能通过场景线索迅速定位灵感。
3. 轻触 **《用一个蓝色花瓶养一株郁金香》** 滑出详情抽屉，点击 **「🗂️ 原始证据 (2)」**，现场展示两条最初录入的时间、地点（*宿舍旁街角花店*）、心情、正在听的歌与原声播放按钮（`mygo/audio`），证明 AI 组织绝不吞没用户原意。

### 第三幕：拒绝平庸与按需落地（60 秒）
1. 展示《有模型与免模型强化学习到底差在哪一步？》的口语化摘要——“就像听一个聪明朋友面聊，而不是在啃 AI 八股文”。
2. 点击 **「🔄 DeepSeek 追问发散」** 演示启发式提问，随后点击 **「✨ AI 帮忙」** 一键展开从前置概念到 30 分钟最小验证的完整 Markdown 行动方案。
3. 点开顶栏 **「🌙 睡眠孵化」**，展示后台 Agent 在夜晚串联起“钴蓝玻璃花瓶”和“手绘噪点着色器”的晨间发现。

### 第四幕：只做好玩的酷分享，绝不做臃肿论坛（45 秒）
1. 切换 **「🌊 漫游与分享」**，点击 **「🖼️ 导出 PNG 视觉卡」** 生成一张带记忆球光晕和场景印章的海报。
2. 浏览只读「他人灵感切片」（如*把游戏引擎 FrameGraph 类比成沙县小吃出菜台*），点击 **「⚡ 与我碰撞」**，把别人的图形学废料和自己的记忆球撞出新灵感。
3. 收尾点题：**“好的工具不做加法。没有评论区、没有关注流，只陪你把转瞬即逝的小火花，稳稳养成真能做出来的东西。”**

## 4. 明确的不做清单（Non-Goals）

- ❌ 不做社区论坛、帖子评论区、关注与热榜（讨论应该留在社交媒体，软件本身保持纯粹）。
- ❌ 不做复杂富文本编辑器与强制文件夹分级（减少记录时的认知摩擦力）。
- ❌ 不在用户无感知的情况下覆写或删除原始录音、原图和原话。
